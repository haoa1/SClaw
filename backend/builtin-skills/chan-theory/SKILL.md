## 缠论核心概念体系

缠论是一套基于几何学的、自洽的市场走势分析理论。它不依赖任何先验的技术指标，而是从 K 线图本身出发，通过严格定义层层递进。

### 第一层：K线包含处理（第73课）

> 原文：第73课 笔-线段与线段-最小中枢结构的不同心理意义

相邻两根 K 线，若一根的高低点完全在另一根范围内，则需合并：
- **向上处理**（向上笔）：取两K线中的 **高高**（最高价取大值，最低价取大值）
- **向下处理**（向下笔）：取两K线中的 **低低**（最高价取小值，最低价取小值）

### 第二层：分型 — 顶分型与底分型（第18课）

> 原文：第22课 走势终完美 | 第23课 基本概念以及定理

**底分型**：三根 K 线，中间 K 线的最低点低于两边，且最高点也低于两边。
```
  高1        高3
   |          |
   |    高2   |
   |     |    |
   |    低2   |
  低1        低3
```

**顶分型**：与底分型相反，中间 K 线的最高点高于两边，最低点也高于两边。

**分型的强弱判断**：
- 第三根 K 线收盘在分型区间内 → 普通分型
- 第三根 K 线收盘跌破底分型最低点（或突破顶分型最高点）→ 强分型
- 第三根 K 线包含关系 → 分型未确认

### 第三层：笔（第73课）

> 原文：第72课 线段划分标准

- 一`笔`由 **相邻的顶分型 + 底分型**（或底分型 + 顶分型）连接构成
- 笔的方向：向上笔 = 底→顶，向下笔 = 顶→底
- 笔的成立条件：顶和底之间必须有至少 1 根独立的 K 线
- 笔是构成线段的最小单元

### 第四层：线段（第72、76、83课）

> 原文：第72课 笔-线段的划分标准 | 第76课 特征序列的包含关系 | 第83课 线段的划分实际应用

- 线段由 **至少 3 笔** 构成
- 线段的方向由第一笔决定
- 线段的结束：被相反方向的线段破坏
- 用 **特征序列** 判断线段是否被破坏：将线段内的笔看作元素，用分型的方法判断特征序列是否出现顶/底分型

### 第五层：走势中枢（第22课）

> 原文：第22课 走势终完美 | 第23课 基本概念以及定理

**缠中说禅走势中枢定义**：某级别走势类型中，被至少三个连续次级别走势类型所重叠的部分。

```
中枢区间 = [max(a2, b2, c2), min(a1, b1, c1)]
```
其中 a1/a2, b1/b2, c1/c2 是三段次级别走势的高点/低点。

**中枢的三种状态**：
1. **中枢延续** — 围绕中枢的波动继续，中枢级别不变
2. **中枢扩张** — 中枢区间变大，形成更高级别中枢（需 9 段以上次级别）
3. **中枢新生** — 产生同方向的新中枢，形成趋势

### 第六层：盘整与趋势（第22、23课）

> 原文：第22课 走势终完美

- **盘整**：任何级别的走势中，只包含 **1 个** 缠中说禅走势中枢
- **趋势**：包含 **2 个以上** 同向的缠中说禅走势中枢（中枢之间不重叠）
  - 上涨趋势：中枢依次向上
  - 下跌趋势：中枢依次向下

### 第七层：背驰（第24、29、30、42课）

> 原文：第24课 学习缠中说禅技术分析理论的关键 | 第29课 MACD对背弛的辅助判断 | 第30课 缠绕、MACD，背弛，中枢 | 第42课 背驰的再分辨

**背驰的本质**：价格走势的力度衰竭，表现为价格创出新高/低，但内在动力减弱。

**背驰的 MACD 辅助判断**：
1. 至少两个同级别中枢（趋势）后才可能出现背驰
2. c 段必须包含对 B 中枢的第三类买卖点
3. c 段必须创出新高（上升趋势）或新低（下跌趋势）
4. MACD 标准形态：黄白线从 0 轴下→0 轴上→回拉 0 轴→再次拉起但高度低于前次

**MACD 背驰判断表**：

| 信号 | 上升趋势顶背驰 | 下跌趋势底背驰 |
|------|---------------|---------------|
| DIF | 新高但低于前高 | 新低但高于前低 |
| 红绿柱 | 面积小于前段 | 面积小于前段 |
| 黄白线 | 回拉 0 轴后再次拉起 | 回拉 0 轴后再次下探 |

**盘整背驰**：只有一个中枢的盘整走势中，进入段与离开段的力度比较。

### 第八层：三类买卖点（第26课）

> 原文：第26课 缠中说禅买卖点分析的完备性

**第一类买点**：下跌趋势底背驰点
- 下跌趋势（至少两个中枢）结束后，最后一次下跌出现底背驰
- 缠论中最安全的买点，100%保证向上一段

**第二类买点**：第一类买点后的回调不创新低
- 第一类买点后出现向上段，然后回踩
- 回踩低点不跌破第一类买点
- 可能出现在中枢下方、内部或上方

**第三类买点**：突破中枢后回踩不进入中枢
- 股价向上突破中枢后，次级别回踩不回到中枢区间
- 是趋势确认的标志
- 之后有两种可能：中枢新生（继续上涨）或中枢扩张（更大级别盘整）

**第一类卖点/第二类卖点/第三类卖点**：与买点对称，方向相反。

### 第九层：走势分解与多义性（第38、41、43课）

> 原文：第38课 走势的多义性 | 第41课 走势类型连接结合性的简单运用 | 第43课 走势类型连接的同级别分解

- **走势终完美原理**（第22课）：任何级别的任何走势类型终要完成
- **同级别分解**：将走势分解为同一级别的走势类型连接
- **多义性**：同一走势可以有多种合理释义，但不等于含糊
- **结合律**：走势类型的连接符合结合律 A+B+C = (A+B)+C = A+(B+C)

### 第十层：中阴阶段（第94、95、104课）

> 原文：第94课 中阴阶段 | 第95课 中阴阶段结束时间的辅助判断 | 第104课 走势结构的两重表里关系（三）

- 走势类型完成到新走势类型开始的过渡阶段
- 中阴阶段的结束由第三类买卖点确认
- 处理中阴的关键：以中枢震荡策略应对，等待突破

### 第十一层：两重表里关系（第96、98、104课）

> 原文：第96课 走势结构的两重表里关系（一）| 第98课 走势结构的两重表里关系（二）| 第104课 走势结构的两重表里关系（三）

**表（分型状态）**：
| 状态 | 含义 |
|------|------|
| (1, 1) | 向上笔延续 |
| (1, 0) | 出现顶分型，可能转折 |
| (-1, 1) | 向下笔延续 |
| (-1, 0) | 出现底分型，可能转折 |

**里（力度）**：MACD 面积、笔的长度等力度指标

## 实战应用框架

### A. 选股策略

| 策略 | 级别 | 信号 | 胜率倾向 |
|------|------|------|---------|
| **底分型 + 缩量** | 日线 | 三K线底分型 + 成交量萎缩 | 高 |
| **底背驰 + 底分型确认** | 日线/30分 | 价格新低 + MACD不新低 + 最近出现底分型 | 最高 |
| **第三类买点** | 日线/30分 | 突破N日区间 + 回踩不破 + 缩量 | 高 |
| **盘整背驰买入** | 30分 | 中枢内离开段力度小于进入段 | 中 |
| **MACD二次金叉** | 日线 | DIF回拉0轴后再次金叉 | 中高 |

### B. 操作级别建议

- **初学者**：日线级别操作（信号稳定，容错高）
- **进阶者**：30分钟级别操作（灵敏度高，适合短线）
- **高手**：多级别联立（区间套背驰确认）

### C. 资金管理

> 原文：第36课 资金管理

1. 单只股票仓位不超过总资金的 20%
2. 第一类买点可重仓（确定性最高）
3. 第三类买点轻仓试探，确认加仓
4. 永远不要用借来的钱炒股（第33课）
5. 散户跟着买点买即可，大资金需要分批建仓（第27课）

### D. 常见误区

1. **背驰不是必然反转** — 小级别背驰可能被大级别延伸消除（第49课 小转大定理）
2. **不要一根筋思维** — 走势有多种可能性（第91课）
3. **没有庄家，只有赢家和输家**（第7课）
4. **你的喜好，就是你的陷阱**（第8课）
5. **技术只是最粗浅的东西** — 战胜贪嗔痴疑慢才是根本（第85课）
